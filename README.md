# STUDENT-ATTENDANCE-MANAGEMENT-SYSTEM

## 1. Project Title
Student Attendance Management System

## 2. Overview of the Project
The Student Attendance Management System is a simple Python-based project developed to manage student attendance in an easy and organized way.

The system allows users to add student records, mark students as Present or Absent, view attendance reports, and search for students using their roll number.

## 3. Features

- Add student records with roll number and name
- Mark attendance as Present or Absent
- Maintain attendance records during program execution
- Generate attendance reports
- Count Present and Absent classes
- Display total classes recorded
- Search students using roll number
- Handle invalid menu choices
- Handle unknown student records
