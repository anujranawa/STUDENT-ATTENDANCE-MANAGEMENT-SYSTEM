## 1.Problem Statement

Managing student attendance manually can be time-consuming and may lead to errors while recording and checking attendance. It can also be difficult to quickly find a student's attendance information when records are maintained manually.

The Student Attendance Management System provides a simple Python-based solution for managing student records, marking attendance as Present or Absent, generating attendance reports, and searching for students using their roll number.

## 2. Scope of the Project


The project focuses on basic student attendance management using Python.

• Adding student records with roll number and name

• Marking attendance as Present or Absent

• Maintaining attendance records during program execution

• Generating an attendance report

• Counting the number of Present and Absent records

• Displaying the total number of classes recorded

• Searching for a student using roll number

• Handling invalid menu choices and unknown students

## 3. Target Users

• Students learning Python programming and basic project development 

• Teachers or faculty members who want to demonstrate basic attendance management

• Small academic groups where simple attendance records need to be maintained

The current version is designed for small-scale academic use and demonstration. Permanent database storage is not included in the current scope.

## 4. High-Level Features

## 4.1 Student Management

The system allows the user to add students using their roll number and name.

## 4.2 Attendance Marking 

The user can mark a student's attendance as Present or Absent.

## 4.3 Attendance Report

The system generates an attendance report showing Roll Number, Student Name, Number of Present classes, Number of Absent classes, and Total Classes.

## 4.4 Student Search

The system allows the user to search for a student using the roll number.

## 4.5 Input and Menu Handling 

The program handles invalid menu choices and checks whether a student exists before marking attendance or searching.
